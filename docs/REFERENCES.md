# 灵感来源 / Inspiration

薪光参考了以下项目的产品思路，并独立实现计薪与桌面界面；没有复制这些项目的源码或视觉资源。
Payrise draws product inspiration from the following projects. Its calculations and desktop UI are independently implemented; their source code and visual assets are not included.

| 项目 / Project | 灵感 / Inspiration |
| --- | --- |
| [PayDance](https://github.com/MrBaoboer/PayDance) | 多种计薪方式、夜班 / Pay modes and overnight shifts |
| [薪动](https://github.com/WizzenH/xindong) | 晚启动补算、调休 / Catch-up estimates and schedule overrides |
| [RealtimeSalary](https://github.com/mereithhh/realtime-salary) | 实时收入反馈 / Live earnings feedback |
| [Paytick](https://github.com/miniLV/Paytick) | macOS 菜单栏、愿望进度 / Menu bar and savings goals |
| [Moyu](https://github.com/dingyiyi0226/moyu) | 休息收入视角 / Earnings during breaks |

项目代码采用 MIT，依赖保留各自许可证。这里的产品参考不构成对其他项目资源的再授权。
