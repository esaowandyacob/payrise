# 产品范围

目标用户：希望在 Mac 菜单栏或桌面角落看到实时收入、获得轻量鼓励的人。

首版优先稳定计薪、随时可见、私密本地保存和可替换主题。已接入窗光、纸页、夜灯三套独立布局，支持即时切换。

## 首版边界

- 不联网获取节假日、汇率或工资；不提供真实考勤、税费及加班工资核算。
- 手动休息计时已实现；自动锁屏/空闲检测尚未实现，防止把所有空闲时间默认归类为摸鱼。
- 当前仅一个愿望目标；多目标、实际存取记录、导入导出是后续功能。
- 未实现开机启动、自动更新、通知提醒、App Store 发布或 Apple 公证。
- macOS 为第一目标；Intel 包需在 Intel Mac 上验证，不能由 Apple Silicon 构建成功推断兼容。

## 后续优先级

1. 继续收集三套主题的使用反馈，完善键盘操作和多显示器体验。
2. 薪资配置生效日期与历史账本，避免配置调整重算过去。
3. 可选本地锁屏/空闲检测，会议状态排除，明确数据边界。
4. 原生登录启动开关、下班提醒、签名公证与用户主动更新。

## 验收重点

- 打开时间不同，不影响同一时刻的收入结果。
- 午夜、跨月、午休、调休、夏令时结果可解释。
- 所有窗口和菜单栏隐私状态一致。
- 新主题不能改变计薪结果或放开远程代码权限。
