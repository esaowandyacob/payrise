# 首版验证记录

日期：2026-11-19。环境：Apple Silicon macOS、Node.js 26.11.1、Electron 45.4.1。命令通过 conda `payrise` 环境运行。

## 已验证

- `npm test`：11 个测试通过。覆盖晚启动、午休、下班封顶、跨午夜/跨月、调休、月薪整月累计、固定天数、时薪、目标、无效参数、夏令时。
- `npm run check`：主进程、preload、核心与渲染脚本语法通过。
- `npm run smoke`：真实 Electron 窗口加载、IPC 读取/保存、非法薪资拒绝、沙箱隔离、主题更新、隐私切换、悬浮窗模式通过。
- 额外截图测试：三套配色渲染成功；主窗口与悬浮窗金额遮罩、设置区隐藏通过。截图使用隔离配置和示例工资。
- `.app` 打包：Apple Silicon 构建成功；使用官方 Electron ZIP，SHA256 与 npm 包内官方校验表一致。
- npm audit：0 项漏洞。为打包工具间接依赖 minimatch 配置 11.0.1 override；完成 Electron 打包验证。

## 本次修复

初次测试在 Electron 的 `quit` 回调中删除临时用户目录，可能与 Chromium 缓存写入并发，引发 `ENOTEMPTY`。现已改成由外部 Node 测试脚本创建隔离目录，等待 Electron 退出后带重试清理；清理异常不再导致应用未捕获异常。
